# Biosfera Aberta

**Uma viagem visual pela vida.**

Experiência educacional gratuita e multilíngue para aprender Biologia por observação, exploração e descoberta. O visitante acompanha a germinação de uma semente, entra em uma célula, explora relações ecológicas e viaja por um modelo anatômico tridimensional.

## Acesse

https://sidineyr.github.io/biosfera/

## Princípios

- Ver antes de nomear.
- Explorar antes de memorizar.
- Relacionar célula, organismo, ecossistema e planeta.
- Diferenciar observação, modelo e evidência.
- Oferecer alternativas acessíveis às experiências visuais e 3D.

## Executar localmente

O projeto não exige instalação:

```bash
python3 -m http.server 8080
```

Abra `http://localhost:8080`.
